# Excel Layout For CATI And CAWI

Keep all current input cells where they already are.

Add this compact block on both `CATI` and `CAWI`, starting around column `AA`:

| Cell | Label / purpose |
|---|---|
| `AA2` | `EMAIL RESPONSE` |
| `AA3` | `Client e-mail` |
| `AB3` | user input |
| `AA4` | `Contact name` |
| `AB4` | user input |
| `AA5` | `Project name` |
| `AB5` | user input |
| `AA6` | `E-mail subject` |
| `AB6` | generated by macro |
| `AA7` | `E-mail draft` |
| `AB7` | generated by macro, wrap text on |
| `AA8` | `Generate draft` button |
| `AB8` | `Send e-mail` button |
| `AA9` | `Status` |
| `AB9` | macro status message |

Recommended buttons:

- On `CATI`
  - button 1: assign `GenerateCATIEmail`
  - button 2: assign `SendCATIEmail`

- On `CAWI`
  - button 1: assign `GenerateCAWIEmail`
  - button 2: assign `SendCAWIEmail`

Recommended formatting:

- `AA2:AB2`: dark fill, white bold text
- `AA3:AA9`: light grey labels
- `AB7`: column width 55-70, row height increased, wrap text
- `AB6:AB9`: thin border

## How to install

1. Save the workbook as `.xlsm`.
2. Open VBA editor with `Alt + F11`.
3. Insert `Module`.
4. Paste in `price-calculator-email.bas`.
5. Add two buttons on each sheet and assign the macros.
6. Save, close, reopen, and enable macros.
